Learning Hub - GitHub Pages package

1. Create a new GitHub repository.
2. Upload the files in this folder (index.html, quiz.html, labs.html, games.html, shared.css) to the repository root. Do not upload the folder itself.
3. Go to Settings > Pages, choose your main branch and the root folder, then save.
4. Your site will be at https://YOUR-USERNAME.github.io/REPO-NAME/

To edit quiz questions, open quiz.html and find the BANK list near the top of the script.
